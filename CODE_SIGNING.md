\# Code Signing Policy — CLIP APP



CLIP APP is an open source software project released under the MIT License.



Official project repository:



https://github.com/pedroromero791/clip.app



\## Code Signing



Official Windows releases of CLIP APP may be digitally signed through

SignPath Foundation's free code signing service for open source projects.



The signing certificate and private key are managed by SignPath Foundation.

The CLIP APP project does not have access to the private signing key.



Signed releases are built from the source code available in this repository.



\## Release Integrity



Official CLIP APP releases are published through the project's GitHub

repository and GitHub Releases.



Users should obtain CLIP APP only from the official repository or its

official GitHub Releases page.



\## Third-Party Components



CLIP APP includes and/or distributes third-party open source components.

Their respective licenses and notices remain applicable to those components.



These components are not represented as original CLIP APP code.
